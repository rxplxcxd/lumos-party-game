# Minispiel-Design – Kategorien, Mechanik-Familien & Lumos-Äquivalente

Grundlage: die Minispiel-Listen der Referenz-PDFs (≈112 Spiele der aktuellen Party-Generation, 100 Best-of-
Spiele und die klassischen Listen). Jedes gelistete Spiel wurde einer **Kategorie** und einer
**Mechanik-Familie** zugeordnet. Pro Familie gibt es in Lumos Party mindestens ein eigenes Spiel mit eigenem
Namen, eigener Welt und eigenen Assets – gleicher Spielfluss, kein übernommenes Design. Spiele, die eine
bestehende Lumos-Mechanik doppeln würden, wurden **nicht** neu gebaut, sondern das vorhandene Spiel erweitert
(Team-/Duell-Varianten, 1-gegen-3-Rollen).

## Kategorien (wie im Vorbild)

| Kategorie | Auslöser auf dem Brett | Belohnung |
|---|---|---|
| **Jeder gegen Jeden** | alle vier auf gleichfarbigen Feldern | 1.: 10 · 2.: 5 · 3.: 2 Münzen |
| **1 gegen 3** | drei Blau gegen einen Rot (oder umgekehrt) | jeder Gewinner 10 Münzen |
| **2 gegen 2** | je zwei Blau und Rot | jeder Gewinner 10 Münzen |
| **Duell** | Duell-Feld, zwei Spieler auf einem Feld im Endspurt | Einsatz geht an den Sieger |
| **Münzen-Spiel** | Münz-Ereignis, Koopathlon | gesammelte Münzen |
| **Glück / Item** | Glücksrad-Kisten-Feld, Item-Ereignis | Münzen / Item |
| **Boss** | Boss-Ereignis (Brettmitte, Endspurt) | Schadens-Rangliste 10/5/2 + Bonus |
| **Showdown** | Start des Endspurts | Sieger des Dreikampfs +20 Münzen |

Grüne (Ereignis-)Felder werden vor dem Minispiel per Farbrad Blau oder Rot zugelost.

## Mechanik-Familien → Lumos-Spiele

| Familie (Beispiele aus den Listen) | Lumos-Spiel | Kategorien |
|---|---|---|
| Einbrechender Boden, Plattform-Überleben | Dungeon Drop, Plank-Panic, Sumo-Schubser | FFA, 2v2, Duell |
| Rollende Hindernisse überspringen (Kugel-/Ball-Chaos) | **Kuschel-Bälle-Hüpfen**, Hammer-Hüpfen | FFA, 1v3 |
| Kreisender Balken, Feuerseil | Hammer-Hüpfen (1v3: Solo steuert den Hammer) | FFA, 1v3 |
| Signal/Farbe ansagen → richtiges Feld (Flaggen, Farben) | **Blumen-Farbenrausch** | FFA |
| Folge merken & nachspielen (Grimassen, Glühbirnen) | **Schlummer-Sternchen-Tanz** | FFA |
| Weitwurf mit Schwung (Hammerwerfen) | **Kürbis-Weitwurf** | FFA, Duell |
| Taktgefühl / Rhythmus | Rhythmus-Tanz, Rhythmus-Küche (Koop) | FFA, 2v2, Koop |
| Sammeln mit Gefahr (Münzregen, Fruchtkorb) | Münzregen, Fischfang | Münzen, FFA, Duell |
| Tauziehen / Kraftmessen | **Seilziehen am Pilzbach** | 1v3, 2v2 |
| Verfolgungsjagd auf Strecke (Piranha-Verfolgung) | **Honigbären-Flucht** | 1v3 |
| Verstecken & Raten (Röhren-Labyrinth, Hütchenspiel) | **Baumhöhlen-Versteck** | 1v3 |
| Solo zielt auf das Trio (Kanonen, Felsen) | Meteor-Ausweichen (1v3: Solo lenkt die Meteore) | FFA, 1v3 |
| Gemeinsames Fahrzeug (Draisine, Paddelboot) | **Schienen-Express** | 2v2 |
| Bälle in Körbe/Tore (Bombsketball, Fußball) | **Sternen-Korbschlacht** | 2v2 |
| Bemalen/Gebiet erobern | Farb-Chaos | FFA, 2v2 |
| Werfen & Treffen | Schneeball-Schlacht, Ballon-Kart-Battle | FFA, 2v2 |
| Heiße Kartoffel | Bomben-Heißer-Hut | FFA |
| Präzision/Stapeln | Turm-Balancieren, Minigolf-Duell | FFA, Duell |
| Hindernisparcours / Rennen | Schleim-Spur Sprint, Geister-Schloss, Schatz-Seilbahn, Lavastrom-Surfen, Kart-Bowling | FFA, 2v2, Duell |
| Einarmiger Bandit, Glücksrad | **Glücks-Glöckchen** | Glück, Münzen |
| Raten, unter welcher Kiste/Geist (Geister-Raten) | **Schatzkisten-Schnüffeln** | Glück |
| Gemeinsam gegen Riesengegner (Boss-Minispiele) | **Boss: Pustebacke, der Wolkendrache** | Boss |
| Mehrstufige Finale (Showdown) | **Lumos-Dreikampf** | Showdown |

Fett = in v1.1 neu gebaut. Alle Spiele unterstützen CPU-Gegner (3 Stufen), Touch, Gamepads und Online-Spiel
(Figuren-Spiele: Besitzer-Autorität mit Interpolation; Zustands-Spiele: Host-Autorität mit Eingabe-Weiterleitung).
